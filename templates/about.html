About the Project

The dashboard helps users explore food prices by commodity, market, region, province, date, unit, and price type. The data source is from The World Food Programme (WFP), Philippines - Food Prices which is refreshed monthly.

The application reads data from a PostgreSQL database (Supabase) and renders server-generated pages with interactive charts and maps in the browser.

Data Pipeline

The data is supplied by the Food Price Watch Pipeline , which performs a weekly ETL (Extract, Transform, Load) from the Philippines - Food Prices .CSV file into a normalized tables in Supabase database.

Features

  • Dashboard summary metrics and filterable price charts
  • Price-observation table with search, sorting, pagination, and selected-observation trends.
  • Commodity table and category-level charts.
  • Market table and a province map showing price-observation and monitored-commodity counts on hover.

Technology Stack

Backend

  • Python
  • Flask and Jinja
  • Flask-SQLAlchemy and SQLAlchemy
  • Psycopg 3 PostgreSQL driver
  • PostgreSQL, configured for an SSL connection

Frontend

  • HTML, CSS and Javascript
  • Bootstrap 5 and Bootstrap Icons
  • Chart.js for interactive charts
  • Leaflet for interactive maps

Bootstrap, Bootstrap Icons, Chart.js, Leaflet, and map tiles are loaded from external CDNs or services and require network access in the browser.
